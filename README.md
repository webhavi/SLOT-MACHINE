              PYTHON SLOT MACHINE 

This is a fun and beginner-friendly Slot Machine game built using Python 🐍. The project simulates a real casino-style slot machine where players can deposit money 💰, choose betting lines 🎯, place bets 💵, and spin the reels 🎲 to test their luck. It is a command-line based game that helps beginners practice important Python concepts such as loops 🔁, functions ⚙️, dictionaries 📚, lists 📋, user input validation ✅, and random number generation 🎰.

The game begins by asking the player to deposit money into their balance 💳. After depositing, the player selects how many lines they want to bet on, with a maximum of three lines available 1️⃣ 2️⃣ 3️⃣. The player then enters a bet amount for each line 💸. Before spinning, the program checks if the total bet exceeds the available balance ⚠️. This creates a realistic betting experience while also demonstrating safe input validation techniques in Python 🧠.

The slot machine uses four symbols: A, B, C, and D 🔤. Each symbol has a different frequency count, which affects how often it appears during spins 🎲. Symbols with lower counts are rarer 💎, while symbols with higher counts appear more frequently ⭐. The reels are generated randomly using Python’s built-in `random` module 🎲, ensuring every spin feels exciting and unpredictable 🎉.

This project is perfect for beginners who want to improve their Python programming skills 💻 while building a fun and interactive application 🎮. The code is organized using functions and constants for better readability 📖 and structure 🏗️. The slot machine results are displayed in a clean grid format 🔲, making the game simple to understand and enjoyable to play 😄.
